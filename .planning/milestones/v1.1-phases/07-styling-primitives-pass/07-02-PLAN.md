Button (CRITICAL for AssetLibrary):
- variant: 'primary' | 'secondary' | 'success' | 'danger' | 'ghost'

- AssetLibrary has the only `<form>` in the codebase; ALL `<Button>` children of that form MUST carry explicit `type="submit"` or `type="button"`.
- disabledButtonStyles baked in via getButtonClasses

Variant mapping (from PATTERNS.md):
- bg-blue-600 → variant="primary"
- bg-slate-700 / bg-slate-600 / bg-slate-500 → variant="secondary"
- bg-green-600 → variant="success"
- bg-red-600/20 / text-red-400 → variant="danger"
- text-slate-400 hover:text-white (icon-only) → variant="ghost" btnSize="sm"
- conditional active/inactive (filter tabs) → KEEP RAW + // allow-raw-html

Size mapping:
- px-2 py-1 / px-3 py-1.5 → btnSize="sm"
