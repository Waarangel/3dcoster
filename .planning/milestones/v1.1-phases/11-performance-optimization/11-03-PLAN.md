<objective>
Create `scripts/assert-bundle-size.mjs` per D-09, mirroring `scripts/lint-no-raw-html.mjs` (the canonical build-gate analog from Phase 07). The script measures the gzipped size of the largest `dist/assets/index-*.js` chunk, exits non-zero with a diagnostic message if it exceeds 300 KB, and on the green path prints the actual KB so headroom is visible. Wire it into `package.json` `scripts.build` AFTER `vite build` per D-09's locked order.

Purpose: Closes the PERF-01 build gate. Without this, a future commit could silently bloat the main chunk above 300 KB and we'd only notice via deploy monitoring. With this, `npm run build` fails fast and visibly.

Output: `scripts/assert-bundle-size.mjs` (~40 lines, Node built-ins only, no third-party imports) and the appended `scripts.build` chain.
</objective>
