    Create `src/utils/formatRelativeDate.ts` exporting a single function `formatRelativeDate(date: Date | undefined): string`:

    - If `date === undefined`, return the literal string `'Never used'` (locked by UI-SPEC §2)
    - Otherwise compute the delta in seconds: `(date.getTime() - Date.now()) / 1000`
    - Pick the largest applicable unit and format via `new Intl.RelativeTimeFormat('en', { numeric: 'auto' })`:
      - `|delta| < 60` → unit `'second'`, value `Math.round(delta)`
      - `|delta| < 3600` → unit `'minute'`, value `Math.round(delta / 60)`
      - `|delta| < 86400` → unit `'hour'`, value `Math.round(delta / 3600)`
      - `|delta| < 604800` → unit `'day'`, value `Math.round(delta / 86400)`
      - `|delta| < 2592000` → unit `'week'`, value `Math.round(delta / 604800)`
      - `|delta| < 31536000` → unit `'month'`, value `Math.round(delta / 2592000)`
      - else → unit `'year'`, value `Math.round(delta / 31536000)`

    For past dates the deltas are negative, which is what `Intl.RelativeTimeFormat` expects (it produces `"3 days ago"` for `value=-3, unit='day'`).

    Cache the formatter at module scope so we don't allocate a new one per call:
    ```typescript
    const rtf = new Intl.RelativeTimeFormat('en', { numeric: 'auto' });
    ```

    Add a JSDoc one-liner: `/** Tiny formatter for "Last used: 3 days ago" / "Never used" labels (Phase 15.1 — UI-SPEC §2). */`
