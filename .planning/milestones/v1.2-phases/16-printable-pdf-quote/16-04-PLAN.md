Quote-number lifecycle (RESEARCH.md Pattern 12; from planning_context section 7) — REQUIRED callback contract:

```typescript
// CostCalculatorProps / JobsManagerProps additions (REQUIRED, not optional):
onPersistQuoteNumber: (job: PrintJob, profile: UserProfile) => Promise<PrintJob>;
//                  ^^^ no `?:` — making this optional silently corrupts quote numbering

// App.tsx implementation contract:
const handlePersistQuoteNumber = async (job: PrintJob, profile: UserProfile): Promise<PrintJob> => {
  // 1. Sequenced atomic writes — BOTH must complete before generator is called
  await db.jobs.put(job);                       // persists { ...job, quoteNumber: N }
  await setUserProfile(profile);                 // persists { ...profile, nextQuoteNumber: N+1 }
  //   (or db.settings.put with the UserProfile JSON blob — whichever idiom App.tsx already uses)

  // 2. Update App-level jobs state so editingJob reflects the persisted quoteNumber on next render
  setJobs(prev => prev.map(j => j.id === job.id ? job : j));

  // 3. Return the persisted job so the caller can pass it to generateQuotePdf
  //    (the caller MUST use this return value — NOT its local variable — to call the generator)
  return job;
};

// Pass to CostCalculator AND JobsManager:
<CostCalculator onPersistQuoteNumber={handlePersistQuoteNumber} ... />
<JobsManager onPersistQuoteNumber={handlePersistQuoteNumber} ... />
```

- First PDF gen for a job (job.quoteNumber === undefined):
  1. Read userProfile.nextQuoteNumber ?? 1
  2. Build updatedJob = { ...job, quoteNumber: newNum } and updatedProfile = { ...profile, nextQuoteNumber: newNum + 1 }
  3. `const persistedJob = await onPersistQuoteNumber(updatedJob, updatedProfile)` — REQUIRED await; the App-level jobs state is updated as part of this call
  4. Call generateQuotePdf with `{ job: persistedJob, userProfile: updatedProfile, sale }` — use the RETURNED job (not the local one) so we are guaranteed in sync with Dexie + App state
- Subsequent PDF gens: job.quoteNumber already assigned (App state was synced on first gen), so skip the persist call and go straight to generateQuotePdf.
