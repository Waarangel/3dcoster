Per gap D (D-16 + D-18), replace JobsManager's silent most-recent-sale fallback with a proper PrintQuoteModal that lets the user pick OR create a customer, enter a per-quote shipping cost, and review a live totals preview before generating the PDF. Output: A new PrintQuoteModal component, unit tests, JobsManager Print Quote button wired to open the modal, App.tsx prop chain cleaned up.

**Critical (CLAUDE.md "Problem-Solving Discipline"):** The modal mirrors Phase 15.1's customer picker pattern exactly. Re-using the existing typeahead + email-match dedup pattern avoids inventing new UX. Calling the createQuote hook action (instead of importing `db` directly) keeps the component Dexie-agnostic and concentrates the multi-store transaction in one place — the hook.
</objective>
