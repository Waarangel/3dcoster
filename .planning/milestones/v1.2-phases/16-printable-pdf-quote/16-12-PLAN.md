## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dexie multi-store transaction | `rw` over `['sales', 'quotes']` — atomic per D-20 explicit lock. Mid-transaction failure rolls back both writes. |
| Quote.customerSnapshot → Sale.customer | Both are JobCustomer-shape snapshots. The convert flow re-uses the modal's editable fields, so the user can adjust customer details for the Sale without touching the Quote's snapshot. By-value rule (D-17 G4) holds. |
| Re-using existing modal | Single-modal pattern avoids divergent code paths. Cancel-clears-convertingFromQuote prevents stale state on next open. |
| Quote patch type narrowing | The patch object's `status` field is typed `RuntimeQuoteStatus` (the narrow enum). Compile-time refusal of 'draft' at this call site mirrors the createQuote site enforcement and closes BLOCKER I-03 symmetrically. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-44 | Tampering | Sale + Quote atomicity | mitigate | Single `db.transaction('rw', [sales, quotes], ...)` enforces rollback semantics. Test 6 covers the rollback case (or punts to plan 16-13 UAT integration coverage if mockable rollback proves intractable). |
| T-16-45 | Repudiation | Convert audit trail | mitigate | `Sale.convertedFromQuoteId` + `Quote.convertedToSaleId` + `Quote.convertedAt` give bidirectional FK + timestamp. Recent Sales back-ref link (16-11) surfaces the audit visibly. |
| T-16-46 | Information Disclosure | Customer field reuse | accept | User explicitly opens Convert flow on a Quote whose customer fields are already on the Quote snapshot — no new PII surface introduced. |
| T-16-47 | Tampering | Stale conversion state | mitigate | Cancel handler clears convertingFromQuote. Conversion state is local to JobsManager; no cross-component leak. |
| T-16-DRAFT-LOCK | Tampering | Accidental 'draft' write at Convert site | mitigate | The Quote patch object's `status` field is typed `RuntimeQuoteStatus` with a `satisfies` clause. TypeScript refuses 'draft' here at compile time (BLOCKER I-03 fix). Symmetric with createQuote in useDatabase.ts. |
