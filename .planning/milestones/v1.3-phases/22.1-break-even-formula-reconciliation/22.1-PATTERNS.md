### `src/db/backfill.ts` (utility, batch)

**Analog:** `src/db/backfill.ts:413-431` — `reconcileCopiesSoldFromSales`; also `src/db/backfill.ts:390-431` for jsdoc pattern

**Existing function signature and structure to mirror** (lines 413-431):
```typescript
export function reconcileCopiesSoldFromSales(
  jobs: PrintJob[],
  sales: Sale[],
): Array<{ id: string; copiesSold: number }> {
  const expectedByJobId = new Map<string, number>();
  for (const sale of sales) {
    const prev = expectedByJobId.get(sale.jobId) ?? 0;
    expectedByJobId.set(sale.jobId, prev + sale.quantity);
  }

  const out: Array<{ id: string; copiesSold: number }> = [];
  for (const job of jobs) {
    const expected = expectedByJobId.get(job.id) ?? 0;
    if (job.copiesSold !== expected) {
      out.push({ id: job.id, copiesSold: expected });
    }
  }
  return out;
}
```

**New function signature and structure** (D-05, Path B chosen per CONTEXT.md D-05 updated 2026-05-27):
```typescript
export function reconcileFixedCostsAtSave(
  jobs: PrintJob[],
  printerInstances: PrinterInstance[],
  printers: PrinterConfig[],
  materials: Material[],
): PrintJob[] {
  // Build O(1) lookup maps
  const instanceById = new Map<string, PrinterInstance>();
  for (const inst of printerInstances) instanceById.set(inst.id, inst);
  const printerById = new Map<string, PrinterConfig>();
  for (const p of printers) printerById.set(p.id, p);

  const out: PrintJob[] = [];
  for (const job of jobs) {
    if (job.fixedCostsAtSave !== undefined) continue;  // idempotent — already snapshotted

    const inst = instanceById.get(job.printerInstanceId);
    if (!inst) {
      console.warn(
        `[reconcileFixedCostsAtSave] orphan job "${job.name}" (${job.id}): ` +
        `printerInstanceId "${job.printerInstanceId}" not found — snapshotting zeros`
      );
      out.push({ ...job, fixedCostsAtSave: { depreciation: 0, nozzleWear: 0 } });
      continue;
    }

    // Mirror calculateDepreciation() — NO failureRate multiplier (fixed cost)
    const purchasePrice = inst.actualPurchasePrice
      ?? printerById.get(inst.printerConfigId)?.purchasePrice
      ?? 0;
    const recoveryMonths = inst.recoveryMonths ?? 12;
    const monthlyHours = inst.estimatedMonthlyPrintHours ?? 40;
    const totalRecoveryHours = recoveryMonths * monthlyHours;
    const depreciationPerHour = totalRecoveryHours > 0 ? purchasePrice / totalRecoveryHours : 0;
    const depreciation = depreciationPerHour * job.printTimeHours;

    // Mirror calculateNozzleWear() — requires PrinterConfig + material density
    const printer = printerById.get(inst.printerConfigId);
    // ... nozzleWear computation using printer.nozzleLifespanCm3 + job.filaments + materials
    // (see costCalc.ts:86-99 for exact formula)

    out.push({ ...job, fixedCostsAtSave: { depreciation, nozzleWear } });
  }
  return out;
}
```

**Jsdoc format to mirror** (lines 390-412): Pure helper, no Dexie imports, idempotent, examples section, "No imports from `dexie` or `./database`" note.

**Key rules:**
- Never mutate job objects from liveQuery cache — always spread: `{ ...job, fixedCostsAtSave: ... }`
- Jobs with `fixedCostsAtSave !== undefined` skip immediately (line: `if (job.fixedCostsAtSave !== undefined) continue`)
- No `failureRate` multiplier on depreciation or nozzleWear (RESEARCH Pitfall 2)
- Export the function so it appears in `backfill.test.ts` import line
