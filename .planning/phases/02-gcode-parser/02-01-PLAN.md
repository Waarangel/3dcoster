**Step 1 — Extend GcodeParseResult interface:**
Add four new required array fields AFTER the existing scalar fields:
```typescript
// --- new array fields (multi-material) ---
filamentTypes: string[];
filamentVendors: string[];
filamentSettingsIds: string[];
filamentGramsPerExtruder: number[];
```
Keep ALL existing scalar fields unchanged (they become computed aliases in the final assembly).

**Step 2 — Add helper function `parseSemicolonArray`:**
Place before `parsePrusaStyle`. Splits a semicolon-delimited value string, trims whitespace, strips surrounding quotes, filters empty strings:
```typescript
function parseSemicolonArray(value: string): string[] {
  return value.split(';').map(s => s.replace(/^"|"$/g, '').trim()).filter(s => s.length > 0);
}
```

**Step 3 — Export `getMaterialDensity`:**
Add `export` keyword before `function getMaterialDensity`. No other changes to this function.

**Step 4 — Update `parsePrusaStyle` (handles PrusaSlicer, SuperSlicer, OrcaSlicer):**
The partial parsers work with `Partial<GcodeParseResult>` so new array fields are optional there. Add these extractions:

a) **filament used [g] — multi-value** (GCODE-02):
Change regex from `([\d.]+)` to `([\d.;]+)` to capture full semicolon-delimited string.
Parse into `result.filamentGramsPerExtruder` array. Set `result.filamentGrams` to `values[0]` for backward compat within the partial parser.

b) **filament_type — multi-value** (GCODE-01):
Change regex from `([^\n;]+)` to `([^\n]+)` to capture full line including semicolons.
Parse into `result.filamentTypes` via `parseSemicolonArray`. Set `result.filamentType = types[0]` for backward compat.

c) **filament_vendor — multi-value** (GCODE-03):
Replace single-vendor regex with full-line capture after `=`.
Parse into `result.filamentVendors` via `parseSemicolonArray`. Set `result.filamentVendor = vendors[0]`.

d) **filament_settings_id — new extraction** (GCODE-03):
Add new regex: `/;\s*filament_settings_id\s*=\s*([^\n]+)/`
Parse into `result.filamentSettingsIds` via `parseSemicolonArray`. Set `result.filamentSettingsId = ids[0]`.

**Step 5 — Update `parseBambuStyle`:**
Bambu calls `parsePrusaStyle` first (inherits Step 4 changes). Then:

a) Update the config-block `filament_type` fallback (around line 183-189):
Change from `.split(';')[0].trim()` to using `parseSemicolonArray`, storing `result.filamentTypes` and setting `result.filamentType = types[0]`.

b) Update `filament_vendor` fallback: capture full line, use `parseSemicolonArray`, store `result.filamentVendors`.

c) Update `filament_settings_id`: capture full line, use `parseSemicolonArray`, store `result.filamentSettingsIds`.

**Step 6 — Update `parseCuraStyle` and `parseIdeaMakerStyle`:**
These are single-material slicers. Wrap their existing single-value results into length-1 arrays:
- If `filamentGrams` found: set `filamentGramsPerExtruder = [filamentGrams]`
- If `filamentType` found: set `filamentTypes = [filamentType]`
- No vendor/settings arrays needed (not present in these formats)

**Step 7 — Update `parseGcode()` final assembly:**
After the slicer-specific parsing and before the return statement:

a) Initialize array defaults from parsed data:
```typescript
const filamentTypes = parsed.filamentTypes ?? [];
const filamentVendors = parsed.filamentVendors ?? [];
const filamentSettingsIds = parsed.filamentSettingsIds ?? [];
let filamentGramsPerExtruder = parsed.filamentGramsPerExtruder ?? [];
```

b) Handle length-to-grams conversion for per-extruder arrays:
If `filamentGramsPerExtruder` is empty but `rawFilamentLength` exists, convert using `getMaterialDensity` and store as single-element array.

c) GCODE-04 — total-only weight distribution:
If `filamentGramsPerExtruder` is empty AND `filamentGrams` is not null, create array `[filamentGrams, ...zeros]` where zeros count = `Math.max(0, filamentTypes.length - 1)`.

d) Pad grams array if shorter than types array:
If `filamentGramsPerExtruder.length < filamentTypes.length`, append zeros.

e) Compute scalar aliases (GCODE-05):
```typescript
filamentGrams: filamentGramsPerExtruder[0] ?? filamentGrams ?? null
filamentType: filamentTypes[0] ?? parsed.filamentType ?? null
filamentVendor: filamentVendors[0] ?? parsed.filamentVendor ?? null
filamentSettingsId: filamentSettingsIds[0] ?? parsed.filamentSettingsId ?? null
```

f) Add array fields to the return object alongside existing scalar fields.
