1. Change the `GcodeImportProps.onImport` callback signature from:
   ```
   onImport: (result: { filamentGrams: number; printTimeHours: number; filamentId?: string; printName?: string; }) => void
   ```
   to:
   ```
   onImport: (result: { filaments: Array<{ filamentId?: string; grams: number }>; printTimeHours: number; printName?: string; }) => void
   ```

2. In `processFile`, after `parseGcode(content)`, replace the single-filament matching with a per-extruder loop:
   ```typescript
   const filaments = result.filamentTypes.map((type, i) => ({
     filamentId: findBestFilamentMatch(
       type,
       result.filamentVendors[i] ?? null,
       assets,
       result.filamentSettingsIds[i] ?? null
     ) ?? undefined,
     grams: result.filamentGramsPerExtruder[i] ?? 0,
   }));
   ```
   If `result.filamentTypes` is empty but `result.filamentGrams` exists, fall back to a single-element array:
   ```typescript
   const filaments = result.filamentTypes.length > 0
     ? result.filamentTypes.map(...)
     : [{ filamentId: findBestFilamentMatch(result.filamentType, result.filamentVendor, assets, result.filamentSettingsId) ?? undefined, grams: result.filamentGrams ?? 0 }];
   ```

3. Update the `onImport` call to pass the new shape:
   ```typescript
   onImport({
     filaments,
     printTimeHours: result.printTimeHours ?? 0,
     printName: printName || undefined,
   });
   ```

4. Change `successInfo` state type from `{ slicer; grams; time; type; matched }` to:
   ```typescript
   interface SuccessInfo {
     slicer: string;
     time: string;
     filaments: Array<{ type: string | null; matched: string | null; grams: number }>;
   }
   ```

5. Build the `successInfo.filaments` array by mapping over the `filaments` array and the `result.filamentTypes`:
   ```typescript
   setSuccessInfo({
     slicer: SLICER_LABELS[result.slicer] || result.slicer,
     time: result.rawPrintTimeString || `${(result.printTimeHours ?? 0).toFixed(2)}h`,
     filaments: filaments.map((f, i) => ({
       type: result.filamentTypes[i]
         ? matchFilamentType(result.filamentTypes[i], result.filamentSettingsIds[i] ?? null)
         : null,
       matched: f.filamentId ? assets.find(a => a.id === f.filamentId)?.name ?? null : null,
       grams: f.grams,
     })),
   });
   ```

6. Update the success toast rendering. Replace the single grams/type/matched display with a stacked list:
   ```tsx
   <div className="flex flex-col gap-1 max-h-32 overflow-y-auto">
     {successInfo.filaments.map((f, i) => (
       <div key={i} className="flex items-center gap-2">
         <span className="text-green-300">{f.grams.toFixed(1)}g</span>
         {f.type && <span className="text-green-300">{f.type}</span>}
         {f.matched && <span className="text-slate-400">-> {f.matched}</span>}
       </div>
     ))}
   </div>
   ```
   Keep the slicer badge and time outside the list. Keep `max-w-sm` on the toast container.
