**GREEN phase:** Create `src/utils/threeMfParser.ts` following the architecture from RESEARCH.md Pattern 1. Key implementation details:

1. Export types: `ThreeMfPlate`, `ThreeMfParseResult`
2. Export async function `parseThreeMf(file: File): Promise<ThreeMfParseResult>`
3. Use `JSZip.loadAsync(file)` to open the ZIP
4. Check for `Metadata/slice_info.config` — if absent, return `{ isSliced: false, plates: [], totalPrintTimeHours: 0, filamentsByType: [], plateCount: 0 }`
5. Parse XML with `new DOMParser().parseFromString(xmlText, 'text/xml')`
6. Iterate `<plate>` elements, extract metadata[key="index"], metadata[key="prediction"]
7. For each `<filament>` child: read id (slot), type, used_g. Filter out entries where grams === 0
8. Fallback: if used_g absent/zero but used_m present, convert using `getMaterialDensity` from `gcodeParser.ts`. Formula: `metres * 1000 * PI * (1.75/2/10)^2 * density` (converts length to volume to mass)
9. Aggregate filamentsByType across all plates (Map keyed by type string, summing grams)
10. Sum prediction seconds across all plates, divide by 3600 for totalPrintTimeHours, round to 2 decimal places

Run tests — all MUST pass.
