**GcodeImport.tsx changes:**

1. Add import at top: `import { parseThreeMf } from '../utils/threeMfParser';`

2. Update `processFile` — at the very start, before the gcode extension check, add a .3mf branch:
```typescript
if (file.name.toLowerCase().endsWith('.3mf')) {
  await processThreeMfFile(file);
  return;
}
```

3. Update the existing gcode extension check to only reject files that are neither .gcode, .gc, nor .3mf (the .3mf case is handled above, so the existing check just needs to not accidentally reject .3mf — which it won't since the .3mf branch returns early).

4. Create `processThreeMfFile` as a `useCallback` (same pattern as existing processFile logic):
   - Set isParsing=true, clear error/successInfo
   - Call `const result = await parseThreeMf(file)`
   - If `!result.isSliced`: set error to `"This 3MF file hasn't been sliced yet. Open it in Bambu Studio or OrcaSlicer, slice it, then export the sliced 3MF."` and return
   - If `result.plateCount === 0 || result.filamentsByType.length === 0`: set error to `"Could not extract print data from this 3MF. The file may be empty or in an unsupported format."` and return
   - Map `result.filamentsByType` to the `filaments` array using `findBestFilamentMatch(f.type, null, assets, null)` for each entry (same matching logic as gcode import)
   - Extract printName from filename: `file.name.replace(/\.3mf$/i, '').replace(/_/g, ' ').trim()`
   - Call `onImport({ filaments, printTimeHours: result.totalPrintTimeHours, printName })`
   - Set successInfo with:
     - `slicer`: `"3MF \u2014 ${result.plateCount} plate${result.plateCount !== 1 ? 's' : ''}"` (em dash, shows plate count per 3MF-04)
     - `time`: `${result.totalPrintTimeHours.toFixed(2)}h`
     - `filaments`: map each entry with type from result.filamentsByType, matched from asset lookup, grams
   - Wrap in try/catch: catch sets error to `"Failed to parse 3MF: ${err.message}"`
   - Finally: set isParsing=false
   - Dependencies: `[assets, onImport]`

5. Update the file input `accept` attribute: change from `".gcode,.gc"` to `".gcode,.gc,.3mf"`

6. Update drop zone label text: change `"Drop .gcode file here or click to browse"` to `"Drop .gcode or .3mf file here or click to browse"`

7. Update supported formats note: add "Bambu 3MF" to the list. Change text to: `"Supports Bambu Studio, PrusaSlicer, Cura, OrcaSlicer, SuperSlicer, IdeaMaker + Bambu/Orca 3MF projects"`

8. Add NewBadge for 3mf-import inline next to the existing gcode-import badge: `<NewBadge feature="3mf-import" />`

9. Update the loading state text: change from `"Parsing G-code..."` to `"Parsing file..."` (since it may be 3MF now)
