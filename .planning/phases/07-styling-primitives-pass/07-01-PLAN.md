Button (src/components/ui/Button.tsx):
- variant: 'primary' | 'secondary' | 'success' | 'danger' | 'ghost'
- btnSize: 'sm' | 'md' | 'lg' (NEVER `size`)
- fullWidth?: boolean
- forwardRef<HTMLButtonElement>
- Disabled styles baked in via `disabledButtonStyles`
- Does NOT default `type="button"` — pass `type=` explicitly inside `<form>` (no `<form>` in these 3 files)

Variant mapping:
- bg-blue-600 → variant="primary"
- bg-slate-700 / bg-slate-600 → variant="secondary"
- bg-green-600 → variant="success"
- bg-red-600/20 → variant="danger"
- text-slate-400 hover:text-white + p-1 (icon-only) → variant="ghost" btnSize="sm"
- conditional active/inactive className (tabs) → KEEP RAW + // allow-raw-html

Size mapping:
- px-2 py-1 / px-3 py-1.5 → btnSize="sm"
- px-4 py-2 → btnSize="md" (default; omit)
- px-6 py-3 → btnSize="lg"

Input (src/components/ui/Input.tsx):
- inputSize: 'sm' | 'md' | 'lg' (NEVER `size` — Omit'd)
- baseStyles: 'w-full bg-slate-700 text-white rounded-lg border-0 placeholder-slate-400 focus:outline-none focus:ring-2 focus:ring-blue-500'
- forwardRef<HTMLInputElement>

Select (src/components/ui/Select.tsx):
- selectSize: 'sm' | 'md' | 'lg' (NEVER `size` — Omit'd)
- forwardRef<HTMLSelectElement>
- baseStyles: 'w-full bg-slate-700 text-white rounded-lg border-0 focus:outline-none focus:ring-2 focus:ring-blue-500'

Structural className tokens to PRESERVE on Input/Select after style-token strip:
- `flex-1` (inside flex containers)
- `w-20` / `w-24` / `w-16` (fixed compact width overrides)
- `text-right` (numeric alignment)
- `col-span-2` / `mt-2` / `pl-9` (layout modifiers)

Tokens to STRIP (baseStyles cover them):
- `bg-slate-700 text-white text-sm px-3 py-2 rounded-lg border-0 focus:ring-2 focus:ring-blue-500`
- `min-h-[44px]` (already baked into md size)
- `disabled:bg-slate-600 disabled:cursor-not-allowed` (already in disabledButtonStyles)
