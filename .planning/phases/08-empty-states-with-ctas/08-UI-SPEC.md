# Phase 8 — UI Design Contract

> Visual and interaction contract for the EmptyState primitive and its three consumer wirings (AssetLibrary, JobsManager, PrinterSettings). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — internal primitives in `src/components/ui/` (Button, Input, Select, Textarea, Card established Phase 7; this phase adds EmptyState) |
| Preset | not applicable |
| Component library | none — React 19 functional components, Tailwind v4 utility classes |
| Icon library | inline SVG (Lucide-style outline aesthetic), `currentColor`, no external dependency per CONTEXT.md D-02 |
| Font | system default (Tailwind v4 default stack) — no custom font loaded |

**Rationale for not adopting shadcn at Phase 8:** Phase 7 just completed a full 14-component primitives pass on this codebase's existing `src/components/ui/` system, with an active grep-based lint guard. Initializing shadcn at Phase 8 would duplicate that work, conflict with the lint guard, and inflate scope. EmptyState is a new entry in that same internal primitives system — Phase 7's chosen path.

Declared values (Tailwind v4 defaults, multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon stroke detail, inline tight gaps |
| sm | 8px (`gap-2`, `p-2`) | NewBadge corner offset (`-top-1 -right-1`) |
| md | 16px (`gap-4`, `mb-4`) | Heading-to-paragraph spacing inside EmptyState |
| lg | 24px (`p-6`, `mb-6`) | Card panel padding (existing JobsManager wrapper) |
| xl | 32px (`mt-8`) | Spacing between paragraph and CTA button |
| 2xl | 48px (`py-12`, `w-12 h-12`) | Vertical empty-state padding; minimum icon size |
| 3xl | 64px (`w-16 h-16`) | Maximum icon size (per CONTEXT.md D-02: 48–64px range) |

**Exceptions for this phase:** none. EmptyState uses pure Tailwind scale. Icon `w-12 h-12` (48px) is the locked default; `w-16 h-16` (64px) only if visual review at UAT calls for a larger anchor.

**Vertical rhythm contract (matches `JobsManager.tsx:197`):**
- `text-center py-12` on outer block
- Icon → 16px below → headline → 8px below → supporting paragraph → 24px below → CTA button

## EmptyState Primitive Contract

This section is additive to the standard UI-SPEC template — it locks the new component's API so the planner and executor have an unambiguous source of truth.

### Props (locked)

```ts
interface EmptyStateProps {
  icon: ReactNode;            // inline SVG element, expected to be 48–64px square, currentColor stroke
  title: string;              // headline (matches D-09 tone)
  description: string | ReactNode; // body paragraph; ReactNode permitted for <br/> mid-paragraph (matches JobsManager.tsx:200-202)
  cta?: {                     // optional — every Phase 8 instance provides one, but the prim must not require it
    label: string;
    onClick: () => void;
  };
  className?: string;         // optional wrapper class for consumer override
}
```

**Rationale for the `cta` object shape** (resolving CONTEXT.md Discretion item):
- Single object groups label+onClick — they're meaningless apart.
- Optional `cta` lets future filter-no-result empty states omit the CTA without an awkward "undefined" pair.
- Matches existing Button primitive's grouped-prop pattern (variant+btnSize together).

### Render contract (locked)

```jsx
<div className={`text-center py-12 ${className}`}>
  <div className="flex justify-center mb-4 text-slate-500">
    {icon}  {/* 48×48 SVG, currentColor */}
  </div>
  <h3 className="text-lg font-semibold text-white mb-2">{title}</h3>
  <p className="text-sm text-slate-500 leading-relaxed max-w-md mx-auto">{description}</p>
  {cta && (
    <div className="mt-6 flex justify-center">
      <Button variant="primary" btnSize="md" onClick={cta.onClick}>
        {cta.label}
      </Button>
    </div>
  )}
</div>
```

**Key contract points:**
- Always renders `text-center py-12` outer (matches `JobsManager.tsx:197`).
- The component does NOT wrap itself in the `bg-slate-800 rounded-xl border border-slate-700` panel — consumers do (matches existing JobsManager pattern at line 195). This avoids double-wrapping when a consumer's existing panel is the wrapper.
- The CTA button MUST be `<Button>` from `src/components/ui/Button.tsx` — never a raw `<button>` (CONTEXT.md D-11). Phase 7's lint guard would otherwise block the PR.
- `max-w-md mx-auto` on the paragraph constrains line length to ~28em for readability across wide list panels.

### Icon contract (locked)

Three icons, all Lucide-style outline aesthetic, 48×48 viewBox, `stroke="currentColor"`, `stroke-width="1.5"`, `fill="none"`, `strokeLinecap="round"`, `strokeLinejoin="round"`. Inline as React components; no external library.

| Screen | Icon concept | Lucide reference name |
|--------|--------------|------------------------|
| AssetLibrary | Box/package (represents inventory of materials) | `lucide:package` style — square outline with horizontal lid line and tab |
| JobsManager | Document/clipboard with line items (represents saved job records) | `lucide:file-text` or `lucide:clipboard-list` style |
| PrinterSettings | Printer (represents the device being tracked) | `lucide:printer` style — printer body with paper tray and output sheet |

**Location decision** (resolving CONTEXT.md Discretion item): create `src/components/ui/icons/` subdirectory with three files (`PackageIcon.tsx`, `ClipboardListIcon.tsx`, `PrinterIcon.tsx`). Rationale: future empty states (Phase 9 skeleton fallback edge cases, filter-no-result later) reuse the icon shapes; co-locating with the primitive avoids drifting copies. Tiny barrel `src/components/ui/icons/index.ts` exports all three.

**Icon size lock:** consumers render each icon at `w-12 h-12` (48px). The icon SVGs themselves accept `className` and forward it to the root `<svg>` so consumers can override (e.g., `w-16 h-16` if a screen needs a larger anchor).
