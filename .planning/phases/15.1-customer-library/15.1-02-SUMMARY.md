### `formatRelativeDate(date: Date | undefined): string`

- Returns the locked literal `'Never used'` when `date` is undefined.
- Otherwise returns `Intl.RelativeTimeFormat('en', { numeric: 'auto' })` output (e.g. `today`, `yesterday`, `3 days ago`, `2 months ago`).
- Module-scope formatter cache — zero allocation per call.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] react-window v2 strict typing on `rowComponent`**
- **Found during:** Task 3 build
- **Issue:** `react-window` v2's `rowComponent` prop is typed to require `ReactElement | null` return; passing a `memo()`-wrapped component (which has the `NamedExoticComponent` type) failed type-checking.
- **Fix:** Followed AssetLibrary's existing pattern — split into two components: `CustomerRowItem` is the `memo`-wrapped heavy render, and `CustomerRow` is a plain-function adapter that accepts the `RowComponentProps<...>` shape and delegates. Identity is still stable across renders because the adapter is module-scope.
- **Files modified:** src/components/CustomerLibrary.tsx
- **Commit:** 9f2e3fa

**2. [Rule 3 — Blocking] `noUnusedLocals` on `showCsvImport`**
- **Found during:** Task 3 build
- **Issue:** TypeScript `noUnusedLocals` flagged the `showCsvImport` value as unread (only the setter was being called) since Plan 03 owns the modal mount.
- **Fix:** Referenced `showCsvImport` via `aria-pressed={showCsvImport}` on the Import CSV button. This satisfies TypeScript AND adds genuine value — the button now shows a "depressed" state while the import modal is open (Plan 03 inherits this automatically when it mounts the modal).
- **Files modified:** src/components/CustomerLibrary.tsx
- **Commit:** 9f2e3fa

**3. [Rule 3 — Blocking] Worktree missing `node_modules`**
- **Found during:** Initial baseline build
- **Issue:** Fresh worktree had no `node_modules/`, so `npx tsc -b` reported missing `react-window` and `rollup-plugin-visualizer` modules.
- **Fix:** Ran `npm install` once at execution start to hydrate dependencies. This is environment setup, not a code change.
- **Files modified:** (none committed — installs land in the gitignored `node_modules/`)
