Quote-number lifecycle (RESEARCH.md Pattern 12; from planning_context section 7):
- First PDF gen for a job (job.quoteNumber === undefined):
  1. Read userProfile.nextQuoteNumber ?? 1
  2. Build updated job: { ...job, quoteNumber: newNum }
  3. Build updated profile: { ...userProfile, nextQuoteNumber: newNum + 1 }
  4. Persist BOTH to Dexie BEFORE calling generator
  5. Call generateQuotePdf({ job: updatedJob, userProfile: updatedProfile, sale })
- Subsequent PDF gens: just call generateQuotePdf({ job, ... }) — generator re-uses job.quoteNumber
