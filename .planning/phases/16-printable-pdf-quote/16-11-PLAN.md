## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Status transition write | Single Dexie write per click — no transaction needed (atomic at row level). |
| Back-ref scroll | DOM-level; no Dexie access. Renders nothing on anomaly (defensive). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-39 | Tampering | Status transitions | mitigate | Single-row updates via `updateQuote`; useLiveQuery re-renders. No state machine validation in v1.2 (e.g., user could in theory click Mark Accepted then immediately click Mark Declined and the latter wins — accepted behavior per D-19 "Mark Accepted / Mark Declined: single-click, no modal"). |
| T-16-40 | Information Disclosure | Status pills + customer name | accept | Section is scoped to the accordion expand — only the job's owner sees it. Same exposure as Recent Sales. |
| T-16-41 | Repudiation | Audit trail | mitigate | Each transition writes `decisionAt = now`. Reopen clears decisionAt to `undefined` (per D-19) so the next decision gets a fresh timestamp. |
| T-16-42 | Denial of Service | Section rendering for users with many quotes | accept | quotesByJobId Map is O(1); per-job filter + sort is O(k) for k quotes per job (typically <20). No pagination needed in v1.2. |
| T-16-43 | NewBadge layout disruption | Recent Quotes section | mitigate | No NewBadge in this section (CLAUDE.md rule honored; single-entry-point convention). |
</threat_model>
