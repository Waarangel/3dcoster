## Final helper signature (src/db/backfill.ts:492-547)

```typescript
export function reconcileFixedCostsAtSave(
  jobs: PrintJob[],
  printerInstances: PrinterInstance[],
  printers: PrinterConfig[],
  materials: Material[],
): PrintJob[]
```

Returns spread-copied `PrintJob[]` (never mutates input). Idempotent — jobs already carrying `fixedCostsAtSave !== undefined` are skipped outright. Orphan jobs (whose `printerInstanceId` does not resolve to any PrinterInstance) get `{ depreciation: 0, nozzleWear: 0 }` and a `console.warn` carrying the job id + name + literal `snapshotting zeros` (D-07). Depreciation and nozzleWear formulas mirror `calculateDepreciation` + `calculateNozzleWear` from `src/utils/costCalc.ts:70-99` — NO `failureRate` multiplier (D-06 / Pitfall 2).
