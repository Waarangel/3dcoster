<critical_constraints>
The app AUTO-SEEDS default printer catalog assets AND default materials into `db.materials` on a brand-new DB (see `useAssets` init in `src/hooks/useDatabase.ts`). Therefore:
- "The user owns a printer" (the auto-skip signal, D-09) MUST be derived from `usePrinterInstances()` (owned physical printers) — which is EMPTY on first run — NOT from the seeded `db.materials`/assets catalog. Auto-skip when `printerInstances.length > 0`.
- The filament step CANNOT assume an empty materials library (it is pre-seeded). Advance it on a NEW filament being added: capture a baseline filament-asset count on step entry and advance when the count increases, or advance immediately when a quick-add tile calls the real add path.
Persistence lives in `UserProfile` JSON under `db.settings` — no Dexie version bump (DB is at v12; mirrors `taxJurisdiction`). NEVER store step state in localStorage (Pitfall M-01).
</critical_constraints>
