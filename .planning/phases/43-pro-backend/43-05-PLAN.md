<objective>
Build the customer-facing hosted quote surface as a Vercel Serverless Function OUTSIDE the SPA bundle (PRO-02 view + PRO-03 security): `api/q/[token].ts` renders a maker-branded page for a valid published token and returns an indistinguishable branded 404 for every other case, with `noindex` + `no-store` headers; the same function accepts an Approve/Decline write via the `approve_quote_decision` RPC; a Supabase Edge Function emails the maker on decision (D-07). Ship the two PRO-03 security regression tests.

Purpose: The research is unambiguous that the SPA's client-side router CANNOT deliver a real HTTP 404, per-token headers, or an uncacheable response (Pitfall 2). This function is the only place that produces correct HTTP semantics. Non-enumerability (D-16) and no-PII-in-CDN-caches (D-08 + no-store) are the PRO-03 gate's core, and they must be proven by automated tests, not eyeballed once.

Output: A live hosted page, an approve/decline loop, an approval email, and two automated security guarantees.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous customer browser → /q/[token] function → RPC | Untrusted token-bearing read/write; capability-scoped by the unguessable token only |
| Database Webhook → edge function → Resend | Server-side outbound email; RESEND_API_KEY never reaches the browser |
| CDN caching of /q/* | no-store prevents caching a response that contained quote data |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-43-01 | Information Disclosure | hosted_quotes enumeration | critical | mitigate | /q function reads via get_hosted_quote RPC only; anon table SELECT revoked (43-01); enumerability regression test enforces it |
| T-43-13 | Information Disclosure | client-rendered fake 404 | high | mitigate | Real Vercel Function returns HTTP 404 + identical body across unpublished/expired/unknown (D-16); tested for byte-equality (Pitfall 2) |
| T-43-05 | Information Disclosure | PII in CDN cache | medium | mitigate | Cache-Control: no-store on every /q/* response; only first-name PII rendered (D-08) |
| T-43-04 | Tampering | forged/replayed decision write | high | mitigate | approve_quote_decision is token-scoped + DB decision-final guard; POST never trusts caller owner identity (D-15) |
