<objective>
Wire the sync data layer under the pure merge core from 44-01: add the Dexie v13 tombstone store, centralize `updatedAt` stamping through a single write wrapper so every store participates in LWW, emit tombstones on delete, and add the transactional applyMerge executor that commits a MergePlan atomically.

Purpose: RESEARCH.md Pitfall 1 is the sharpest risk in this phase — scattering updatedAt stamping across the ~8 independently-maintained CRUD hooks invites a missed call site, which silently breaks LWW for that store (an un-stamped newer edit loses on merge). A single choke-point wrapper + a grep audit of every write site is the mitigation. Pitfall 2 requires the tombstone-aware merge to stay separate from the destructive restoreBackup path.
Output: syncStamp.ts wrappers, v13 store, applyMerge.ts transaction executor, useDatabase.ts routed through the wrapper, tests.
</objective>
