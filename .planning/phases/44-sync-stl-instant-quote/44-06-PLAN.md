## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cloud-folder → app | The sync file round-tripped through the user's cloud folder is untrusted on read |
| tab ↔ tab | Concurrent tabs racing the debounced auto-write and launch check |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-44-06-01 | Tampering | merge without confirm | high | mitigate | A divergent merge is never auto-committed — SyncMergeSummary confirm gates applyMerge (roadmap success criterion 2) |
| T-44-06-02 | Tampering | multi-tab race | high | mitigate | The whole read→merge→write cycle (debounced write + launch check) runs inside the single shared withSyncLock (44-04) |
| T-44-06-03 | Denial of Service | bad merge / data loss | medium | mitigate | Pre-merge buildBackupFile snapshot + one-click 'Restore pre-merge state' undo (D-08); applyMerge is atomic (44-03) |
| T-44-06-04 | Tampering | oversized sync file | medium | mitigate | Reuse MAX_BACKUP_BYTES cap before .text()/JSON.parse on the sync file read (same gate as BackupRestoreSection restore) |
</threat_model>
