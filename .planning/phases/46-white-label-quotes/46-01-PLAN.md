| client → stored UserProfile → (later) hosted-page HTML | The produced data URL is persisted and, in 46-05, interpolated into HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-46-01 | Tampering / Elevation | logoDataUrl in downstream HTML `<img src>` | high | mitigate | `isValidLogoDataUrl` strict allowlist (`data:image/(png\|jpeg\|webp);base64,` + base64 alphabet only) is defined here and reused at every write/render site; svg and attribute-breakout payloads rejected |

| T-46-SC | Tampering | npm installs | low | accept | No new packages this phase (RESEARCH: vanilla Canvas). If `browser-image-compression` is ever added, the Package Legitimacy Gate applies first. |
