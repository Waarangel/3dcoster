<objective>
The cloud transport layer — the direct sibling of `syncFileIO.ts`, but talking to one Supabase `sync_blobs` row per account instead of a Dropbox folder. It moves opaque ciphertext strings only (encryption/decryption is the hook's job via 47-03), implements the compare-and-swap upload with a re-fetch/re-merge/retry loop (RESEARCH Pattern 1 — the phase's core new risk), the `reset_sync_blob` path (D-07), the last-known-version persistence, and the Supabase Realtime Broadcast notify on a private per-account channel (D-02).

Purpose: The local Web Lock only serializes tabs ON ONE DEVICE — it has no reach into a second physical device (RESEARCH Pitfall 1). The server-side CAS on `version` is what actually closes the cross-device lost-update race. This module owns that transport-level defense.
Output: `cloudBlobIO.ts` + tests (mocked Supabase RPC).

Depends on 47-02 (the RPC + Realtime RLS contract) and 47-01 (inventory-first: the FIRST code that transmits user data server-side must land after the disclosure — locked sequencing).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device ⇄ sync_blobs row | Concurrent cross-device writes to a shared remote resource |
| Realtime channel → open devices | A notify message triggering a pull-and-merge |
| free-floor (signed-out) → Supabase | Must remain zero-network |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-47-04 | Tampering (lost update) | uploadWithRetry / CAS | high | mitigate | RPC CAS (47-02) + re-fetch/re-merge/retry loop; a stale write is rejected, never clobbers |
| T-47-11 | Tampering (rollback replay) | stale-version write | medium | mitigate | same CAS clause rejects any write against a version ≤ current |
| T-47-05 | Spoofing | forged broadcast → spurious pull | medium | mitigate | private channel + realtime.messages RLS (47-02); a spurious pull is harmless anyway (re-merge is idempotent) |
| T-47-12 | Information Disclosure | ciphertext/PII in notify payload | high | mitigate | payload restricted to { version, updatedAt } (D-08); ciphertext never broadcast |
| T-47-13 | Info Disclosure (free-floor leak) | signed-out network call | high | mitigate | every path guards on non-null supabase + signed-in user (PRO-01) |
</threat_model>
