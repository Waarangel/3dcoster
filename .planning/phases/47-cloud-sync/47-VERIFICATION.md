## Spot-checks performed (line-level, highest-risk claims)

The broadcast payload (`cloudBlobIO.ts:305-306`) carries only `{version, updatedAt}`.
2. **CAS version compare in `upload_sync_blob`.** `0002_cloud_sync.sql:148-155`: `update ... where user_id = auth.uid() and version = p_expected_version returning version`; insert-at-version-1 path only when `v_row_count = 0 and p_expected_version = 0` with `on conflict (user_id) do nothing` (`:159-168`) — a concurrent first-upload race cannot double-insert, and a stale writer gets `accepted: false`, driving `uploadWithRetry`'s bounded re-merge loop (`cloudBlobIO.ts:127-138`).
