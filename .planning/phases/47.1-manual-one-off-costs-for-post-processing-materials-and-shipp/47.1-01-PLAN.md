<objective>
Tracer-first slice of Phase 47.1: a user can add a one-off post-processing cost (name + cost, no library asset) in the calculator, see it in the Cost Breakdown, and save it on the job, with the saved `costPerUnit` including it. This one path runs through every layer the phase touches: type, pure cost math, derived-values hook, form-state hook, section UI, orchestrator save. Task 2 then builds the pure input-hardening helpers (untrusted-input sanitizer + save normalizer) test-first. Plan 47.1-02 wires those helpers in and adds the packaging list.

Purpose: Prove the architecture end-to-end on the motivating case (the founder's $200 auger, SOURCE-TODO.md) before expanding to packaging, the save prompt, and downstream consumers. Implements D-02 (full cost charged to the job, no amortization) and D-07 (the one-off cost is charged flat, not multiplied by the failure-rate factor), and starts D-06 (free tier, no gating).
Output: `ManualCostLine` type + two optional `PrintJob` fields, `calculateManualLinesCost`, `src/utils/manualCostLines.ts`, the one-off row UI in Post-Processing Materials, and the end-to-end integration test.
