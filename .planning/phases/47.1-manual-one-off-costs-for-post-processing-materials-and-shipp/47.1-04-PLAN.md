<objective>
Build the founder's second ask (SOURCE-TODO item 2, MC-05). When a job with not-yet-asked one-off lines is saved, a pre-save popup offers, per line, "Keep as one-off" (default) or "Add to library". Accepted lines become library assets for future jobs. The job keeps every line by value either way (D-03). Cancel or Escape aborts the save (D-04). Already-asked lines and lines whose name already exists in the library are never re-asked. Also adds the CHANGELOG `[Unreleased]` entry (MC-07), with no version bump and no tag.

Purpose: one-time purchases stay one-off, and reusable items join the library with one click, without double counting or phantom stock.
Output: pure prompt helpers, the `SaveToLibraryModal` presenter, the orchestrator save flow with the new `onAddAsset` prop, App wiring, the fixture update, integration tests, and the CHANGELOG bullet.

Discretion choices (CONTEXT "Accepted research recommendations" + Claude's Discretion), recorded here:
- The default category for a post-processing asset is **Tools**, because the founder's motivating item (a $200 auger) is a tool. The row's category Select appears only when "Add to library" is chosen, offering Tools / Finishing / Consumables (AssetLibrary's own labels).

- Accepting does not seed stock on hand (RESEARCH Open Question 6). The asset's stock stays unset.
- The modal's confirm button reads "Save job" or "Update job" to match the action the user started.
