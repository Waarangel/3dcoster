# Phase 47.1 — Context (founder decisions)

Captured 2026-10-18 from the founder's note (SOURCE-TODO.md) and the post-research decision round.
These are LOCKED: planners and executors must not re-decide them.

## Goal
Users can add manual one-off cost lines (name + cost) to Post-Processing Materials and to
Shipping → Packaging Materials without needing a library asset. When the job is saved, a popup
offers, for each line, "add to asset library?". Motivating example: a $200 auger bought for one
product.

## Locked decisions
- **D-01 (scope of "Shipping"):** manual lines go in the **Packaging Materials** list only.
  Carrier Cost already accepts any typed number and is unchanged. No multi-line carrier costs.
- **D-02 (cost semantics):** the full cost is charged to the job. Amortizing a reusable tool
  across uses is OUT of scope (possible later feature).
- **D-03 (after "Add to library"):** the job's line **stays a by-value manual line** at the cost
  the user typed. The new library asset is only for future jobs. No conversion to a library link,
  so no double counting and no stock deductions against the new asset.
- **D-04 (popup timing):** **pre-save** modal, shown when the user clicks Save Job and the job has
  manual lines that haven't been asked about yet. Each row defaults to "Keep as one-off".
  Cancel or Escape returns to editing and does NOT save. Lines already asked about
  (`libraryPrompted`) are not asked again. Lines whose name already exists in the library
  (case-insensitive, same kind) are skipped.
- **D-05 (quotes):** manual packaging does **not** feed the shipping pre-fill on quotes, matching
  library packaging today. It only affects cost and profit math.
- **D-06 (tier):** free-tier feature, on both web and desktop. Not gated behind Pro.

## Accepted research recommendations
- Data shape: optional `manualMaterials?` and `manualPackaging?` arrays on `PrintJob`, each item
  `{ id, name, cost, libraryPrompted? }`. Don't overload `MaterialUsage`. Write `undefined` when
  empty. No Dexie version bump, no reconcile helper, no Supabase change.
- Category for popup-created post-processing assets: a per-row Select (Finishing / Tool /
  Consumable). Packaging assets are always `packaging`.
- The popup uses the shared `Modal` and `Select` (lint:no-raw-html); row removal uses
  `RemoveButton`; cost inputs use `compact` and display at 2dp.
- Add a NEW badge (`manual-cost-lines`) and a CHANGELOG `[Unreleased]` entry. No version bump or tag.
