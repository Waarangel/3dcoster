<objective>
Fix the bug where newly-added filaments in the Asset Library never appear in the Cost Calculator's `FilamentSelector` dropdown. Close every gate that drops a legitimately-added filament at BOTH the save layer and the read layer, and heal already-saved `currency: undefined` filaments in production via a one-time idempotent reconcile.

Purpose: A filament a user adds (and correctly categorizes as a filament) must always become selectable in the Cost Calculator. Today it is dropped 100% of the time by the currency gate (`FilamentSelector.tsx:34`) because the material form has no currency input, and brand-less filaments are additionally dropped by the brand-grouping gate.

Output:
- Save layer writes correct `currency` going forward (AssetLibrary + App.tsx).
- Read layer tolerates legacy/missing currency and renders brand-less filaments (FilamentSelector).
- A pure idempotent `reconcileFilamentCurrency` heals existing `null`-currency filaments (backfill.ts + useDatabase.ts wiring).

Root-cause analysis with exact file:line citations: see RESEARCH.md in this directory.

SCOPE LOCKS (do NOT touch):
- The CAD-vs-USD seed mismatch (default profile = CAD, seeded Bambu filaments = USD) is DEFERRED. Do NOT add FX conversion, currency-agnostic rewrites, or rewrite seed currencies. The read-layer rule stays `currency === userCurrency || currency == null` — tolerate ONLY null/undefined, never a different explicit currency.
- Do NOT force new assets to category 'filament'. The "All" tab default of 'consumable' is intentional. The fix relies on the user's manual category selection continuing to work.
- Add NO new form controls. If a control were ever needed it MUST use shared `./ui` components (pre-commit lint guard scripts/lint-no-raw-html.mjs forbids raw `<select>`/`<input>`). The recommended fix adds none.
</objective>

export function reconcileQuoteCurrency(quotes: Quote[], currency: string): Quote[] {
  if (currency === 'USD') return [];
  const out: Quote[] = [];
  for (const q of quotes) {
    if (q.lineItemsSnapshot?.currency !== 'USD') continue;
    out.push({ ...q, lineItemsSnapshot: { ...q.lineItemsSnapshot, currency: currency as Currency } });

}
