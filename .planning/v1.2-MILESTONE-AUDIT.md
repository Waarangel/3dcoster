## Architectural Strengths (beyond stated wiring)

The integration check surfaced three locks that make the system **more** integrated than originally claimed:

1. **PDF locked to Quote snapshot, not Sale/Job.** Single-arg `generateQuotePdf(quote: Quote)` signature is compile-time enforcement of the snapshot rule (Phase 16 D-17 G4). Edits to source PrintJob/UserProfile cannot mutate already-issued quotes.
2. **Quote.status type narrowing (G6 lock).** `RuntimeQuoteStatus = Exclude<QuoteStatus, 'draft' | 'accepted'>` is enforced at both runtime write sites. TypeScript refuses `'draft'` at the call site.
3. **Atomic Convert-to-Sale.** Sale.add + Quote.put + job.copiesSold bump all run in ONE `db.transaction('rw', ...)` with an explicit `[DO NOT REMOVE THIS BUMP]` comment defending against historical regression.
