### H10. Customer picker state triplet + `filteredCustomers`/`visibleCustomers` memos duplicated

**Files:** [JobsManager.tsx:1025–1240](src/components/JobsManager.tsx:1025) ↔ [PrintQuoteModal.tsx:65–133](src/components/PrintQuoteModal.tsx:65)
**Severity:** MEDIUM
**Category:** cross-file-duplication

Both manage `[customerPickerQuery, setCustomerPickerQuery]`, `[customerPickerOpen, setCustomerPickerOpen]`, `[customerPickerActiveIndex, setCustomerPickerActiveIndex]`, then derive identical `filteredCustomers` (substring filter on name/email) and `visibleCustomers` (sliced to limit). `PrintQuoteModal.tsx` explicitly labels this "mirror 15.1-04 verbatim" at line 120 — the copy was deliberate but the comment confirms it should eventually become a hook.

**Recommended hook:**

```ts
// src/hooks/useCustomerPicker.ts
export function useCustomerPicker(customers: Customer[]) {
  const [query, setQuery] = useState('');
  const [open, setOpen] = useState(false);
  const [activeIndex, setActiveIndex] = useState(0);
  const filteredCustomers = useMemo(() => /* substring filter */, [customers, query]);
  const visibleCustomers = useMemo(() => filteredCustomers.slice(0, PICKER_VISIBLE_LIMIT), [filteredCustomers]);
  const handleKeyDown = useCallback(/* ArrowUp/Down/Enter/Escape/Tab */, [/* ... */]);
  const reset = useCallback(() => { setQuery(''); setOpen(false); setActiveIndex(0); }, []);
  return { query, open, activeIndex, visibleCustomers, filteredCustomers, setQuery, setOpen, setActiveIndex, handleKeyDown, reset };
}
```

Collapses ~80 lines per component into a one-line hook call. Closes H2, H9, H10 together.
