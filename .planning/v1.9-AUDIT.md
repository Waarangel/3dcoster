## Tier 1 — Fix before v1.9 (real bugs / user-facing)

### Data integrity (Dexie / local-first)
- **[CRITICAL] Deleting an asset orphans its stock events** — `deleteAsset` (`useDatabase.ts:221`) only removes the material row; stock-event rows keyed on `assetId` are never deleted (no cascade). Orphans bloat backups and can **resurrect phantom stock** if an id is reused (e.g. reset-to-defaults). Fix: transactional cascade — `db.transaction('rw', db.materials, db.stockEvents, …)` deleting `stockEvents.where('assetId').equals(id)` (assetId already indexed).
- **[HIGH] 🟦 Intentionally-deleted defaults resurrect on reload; default-printer edits get clobbered** — `useAssets` init (`useDatabase.ts:79-148`) re-seeds defaults by category-count/probe-id, and `bulkPut`s default printers (overwriting user edits to a default printer's wattage/price). "I deleted it and it came back." Fix (after decision): gate per-category re-seeds behind a persisted "did-seed" flag; probe per-row instead of bulkPut-ing whole catalogs; document the contract.
- **[HIGH] Job save/edit stock deduction is non-atomic** — `addJob`/`updateJob` (`useDatabase.ts:797-821`) write the job, then deduct stock in a *separate* transaction; the writer comment claims atomicity but neither call site wraps it. A failure between the two awaits overstates inventory, and there's no boot-reconcile to self-heal (only re-saving that job fixes it). Fix: wrap both in one transaction, or add a stock-events boot reconcile; correct the misleading comment.
- **[MEDIUM] `backfillCustomersFromSales` cross-tab race** can mint duplicate customers (in-memory dedup, non-unique email index). Persist a "done" flag or dedupe at read.
- **[MEDIUM] 🟦 Stock unit mismatch risk** — job deduction uses raw `MaterialUsage.quantity`; stock-on-hand UI sets level via `unitsPerPackage`. Confirm both share a unit basis or stock drifts.
- **[LOW] `logManualAdjustment` / `addPrintHours`** — no `Number.isFinite` guard / non-transactional RMW. Cheap guards.

### Cost / pricing (core value)
- **[HIGH] Fixed marketplace fees are hardcoded USD but added to non-USD selling prices** — `etsyPaymentFixed 0.25`, `etsyListingFee 0.20`, `facebookMinFee 0.80` (`CostCalculator.tsx:451-473`) are never FX-converted. A JPY Etsy seller gets ~¥0.45 instead of ~¥70 (≈150× off), so platform-fee + Net Profit/Margin readouts are wrong. Fix: convert the fixed constants through the FX table (mirror `convertToProfile`); percentage fees are fine.
- **[MEDIUM] 🟦 "Platform Fee" shown but not in saved profit/costPerUnit** — quoted margin is gross (fee shown separately) while sales-report profit subtracts the fee on the revenue side → asymmetry. Decide: document as pre-fee, or fold fee into `trueCost`/interlink.
- **[LOW] Negative-value inputs** (grams, print time, model cost) accepted → negative trueCost freezes the pricing fields. Add `min="0"` + `Math.max(...,0)`.
- **[LOW] `formatCurrency`** renders `NaN`/`∞` literally — add `if (!Number.isFinite(amount)) return '—'`.

### Accessibility (v1.9 is the a11y release; Phase 35 didn't reach these)
- **[HIGH] Main App tab bar has no arrow-key / roving-tabindex** (`App.tsx:277-310`) — SettingsModal already has the correct pattern; App.tsx must match. (Flagged in a prior review too.)
- **[HIGH] Unlabelled modal form inputs** — PrintQuoteModal (4 customer fields, `PrintQuoteModal.tsx:333-366`) and PrinterSettings add/edit forms (`PrinterSettings.tsx:195-228, 426-468`) have `<label>` without `htmlFor`/`id`. Fails axe. Mirror the `useId()` pattern already used in RecordSaleModal/CustomerEditModal.
- **[HIGH] `window.confirm` for destructive delete** in CustomerLibrary (`:191`) and PrinterSettings (`:166`) — inconsistent with the styled `Modal`/`ResetAssetsModal` standard; replace with a shared `ConfirmModal`.
- **[HIGH] Error banners without `role="alert"`** — RecordSaleModal (`:411`) + PrintQuoteModal (`:424`) save errors aren't announced.
- **[HIGH] Misc** — overflow `role="menu"` lacks arrow-key nav (JobsManager); CSV row checkboxes unlabelled; UpdateBanner has no `role="status"`; ImageCarousel auto-advances with no pause (2.2.2); Header hamburger missing `aria-controls`; FeedbackPage raw `<button>` (no focus ring).
- **[MEDIUM] Marketing pages** — no `<main>` landmark on any page; sections not `aria-labelledby`'d; CSV drop zone not keyboard-operable; ReportsSection live-preview no `aria-live`; clear-search `×` buttons need `aria-label`.
- **[LOW] Decorative SVGs** missing `aria-hidden` (LandingPage/Footer/UpdateBanner); PageLoading no `role="status"`.

## Tier 2 — Hardening (security + perf; mostly post-decision / low-risk)

### Security (strong posture overall — strict CSP, no XSS, no secrets, CSV/backup/JSON all sanitized)
- **[HIGH] dev-dependency CVEs** (`npm audit` = 19, all build/dev-only — vite/babel/jspdf→dompurify) — none ship to users. `npm audit fix` + rebuild/retest before tag; note any unavoidable dev-only CVEs.
- **[MEDIUM] `isSafeHttpUrl` is a prefix check** (`urlSecurity.ts`) — upgrade to a WHATWG-`URL` parser to close encoded-scheme edge cases for all link sites at once; then point `ChangelogPage` at it (drops a duplicated check).
- **[MEDIUM] Announcement pinned to mutable jsDelivr `@main`** — phishing surface if CDN/repo compromised (message + CTA url are remote-controlled, though rendered as escaped text). Pin to a tag/SHA. FX stays display-only (good) — lock with a regression comment.
- **[MEDIUM] Tauri `fs:allow-write-file` scope is `$HOME/**`** — narrow to Downloads/Documents/Desktop (the save-dialog targets).
- **[MEDIUM] 3MF parser has no decompressed-size guard** (`threeMfParser.ts`) — zip-bomb / memory-exhaustion on a crafted `.3mf`; cap entry size + file-size at the input.
- **[LOW] `withGlobalTauri: true`** — flip to false if `window.__TAURI__` is unused (code uses dynamic imports).

### Performance (mature codebase — virtualized + memoized; no critical issues)
- **[MEDIUM] AssetLibrary `filteredAssets`/`displayAssets`** are inline `.filter()` (new identity each render) → defeats the `searchedAssets`/`sortedAssets` memos. Wrap in `useMemo` keyed on `[assets, filterCategory]`.
- **[LOW] FilamentSelector** mounts a `document` mousedown listener while closed (up to 16 rows) — gate on `isOpen`.
- **[deferred] Pricing interlink** is a setState-in-effect smell — correct today, slated for the v2.0 CostCalculator split (do NOT change in v1.9; the PERF-11 dep-trim revert stands).
