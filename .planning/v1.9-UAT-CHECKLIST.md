# v1.9 UAT Checklist

**Before testing:** clear the stale service worker — DevTools → Application → Service Workers → **Unregister** → hard reload (⌘⇧R). Otherwise the browser serves old JS.

App: http://localhost:4173/ → **/app**. Priorities: **P0** = core value + this session's risky changes (must pass), **P1** = important, **P2** = polish.

## P0 — Cost & Pricing (core value; the net-margin change is the riskiest unverified-in-UI item)
- [ ] **No marketplace selected:** enter cost inputs, set Profit Margin (e.g. 40%) → Selling Price + Target Profit derive correctly. Edit **Selling Price twice in a row** → margin/profit update **both** times (no freeze). Repeat editing Margin twice and Profit twice.
- [ ] **Etsy selected:** the same 40% margin now yields a **higher selling price** (fee folded into net); the **Net Profit / Net Margin** readout reflects ~40% **after** the fee. Switch back to **None** → price returns to the gross figure.
- [ ] **Non-USD (set currency to JPY in Settings):** select Etsy → the **fixed** fee component is sensibly scaled to ¥ (not a fraction of a yen). Sanity-check the platform-fee line against the real Etsy fee.
- [ ] **Saved job on a marketplace:** save a job sold via Etsy → Jobs tab → the break-even pill + profit reflect the fee (net), consistent with the Reports numbers.
- [ ] **Negative input guard:** type a negative grams / print time → clamps to 0 (no negative price, fields don't freeze).
- [ ] **Missing FX rate:** a converted price with no rate shows **"—"**, never "$NaN".

## P0 — Asset Library (heavily reworked this session)
- [ ] **Add button tracks the tab:** All → "Add Asset"; Filament tab → "Add Filament"; custom "Tester" tab → "Add Tester". Defining a NEW category (+ New) → **"Add Category"**.
- [ ] **Scoped + honest Reset:** Reset Filaments restores **only** filament defaults (consumables/custom untouched); Reset All restores all materials but **keeps** custom categories; Reset Tester (custom) → modal says "remove all Tester assets", clears only Tester.
- [ ] **Custom-category data safety:** create "Tester" + add an asset; go to All → Reset All → **Tester survives**. Reset Tester → Tester cleared, lands on **All** with tabs intact.
- [ ] **Empty view never strands you:** empty a category → filter tabs stay visible; the empty-state "Add X" button opens the form.

## P0 — Data integrity (test over a RELOAD)
- [ ] Delete a **default** material (e.g. a Bambu filament) → reload → it **stays gone** (no re-seed).
- [ ] Edit a **default printer's** wattage/price → reload → your edit **survives** (not clobbered).
- [ ] Delete an asset that had stock-on-hand set → re-add an asset with the same id → stock starts at **zero** (no phantom resurrection).
- [ ] Set stock on a filament, log a job using it → stock **deducts**; edit/delete the job → stock **self-corrects**.

## P1 — Accessibility (keyboard + VoiceOver; the new items)
- [ ] **Main app tabs:** focus a tab, press →/← repeatedly → focus moves tab-to-tab, wraps; Home/End jump. (New this session.)
- [ ] **Settings inner tabs:** same arrow-nav (Phase 35).
- [ ] **VoiceOver (⌘F5):** tab switches announce; a form error in Asset/PrintQuote/RecordSale modals announces immediately (role=alert); FilamentSelector announces "Filament"; the ⓘ tooltip says "More information", Escape dismisses it.
- [ ] **Confirm modals:** delete a customer / printer → a **styled** confirm modal (not a browser `window.confirm`), focus trapped, Escape cancels, focus returns to the trigger button.
- [ ] **Carousel:** a Pause/Play control exists; with "Reduce Motion" on (System Settings → Accessibility), it doesn't auto-advance.
- [ ] **Modal form labels:** Tab through PrintQuote + PrinterSettings-add forms → every field has a label (clicking the label focuses the field).
- [ ] **Marketing pages:** a screen reader's "jump to main content" lands in the page body (new `<main>`).
